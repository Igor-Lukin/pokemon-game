1. РЕШЕНИЯ ВЛАДЕЛЬЦА (зафиксировано)
--------------------------------------------------------------------
  - SVG отвергнут. Арт — РАСТРОВЫЙ PNG.
  - Механика paper-doll: есть основной арт (ТЕЛО-«болванка»), сверху «натягиваются»
    слои — лицо (глаза/нос/рот), волосы/причёска, одежда. «Надел» = показать слой.
  - Одежда = ОТДЕЛЬНЫЙ ПРЕДМЕТ игры (как решено в [7]).
  - Тело-болванка: БЕЗ глаз/рта/носа/волос, только нижнее бельё. Всё остальное —
    слоями поверх. Отдельно муж. и жен. болванка.
  - Framing болванок — ВЗРОСЛАЯ нейтральная фигура-манекен (чтобы не сексуализировать
    и не ловить фильтры).

2. КАК РЕАЛИЗУЕТСЯ КОМПОЗИЦИЯ (техрешение, подтверждено «да, можно»)
--------------------------------------------------------------------
Два способа (выбор при написании ТЗ механики):
  (A) СЛОИ НА КЛИЕНТЕ (рекомендовано, проще): база + каждый предмет = прозрачные PNG
      ОДНОГО холста, выровненные; накладываются стопкой (наложенные <img> или
      <canvas> drawImage). Отдельный файл не генерируется — визуально это и есть
      одетый аватар. Мгновенно.
  (B) СЕРВЕРНАЯ СБОРКА одного PNG: Go нативно (image, image/draw, image/png) рисует
      базу + слои по z-order -> один файл, кешируется. Нужно, если понадобится
      ЕДИНАЯ картинка (шаринг/превью/чужой профиль).
Z-ORDER слоёв (пример): фон-рюкзак → ТЕЛО → лицо → штаны → торс(куртка) → волосы →
  головной убор. Точный порядок утвердим с артом.
ГЛАВНОЕ ТРЕБОВАНИЕ К АРТУ: все PNG — с прозрачностью, ОДИН холст, ВЫРОВНЕНЫ по телу
  (кепка на голову, куртка на торс). Иначе никакой код не спасёт.

3. АРТ-ПАЙПЛАЙН (как владелец делает картинки)
--------------------------------------------------------------------
  - Инструмент: Stable Diffusion локально (Fooocus / ComfyUI / A1111) — бесплатно,
    даёт контроль (ControlNet/inpaint). Прозрачность: remove.bg или Photopea.
  - Единый ХОЛСТ для всего, напр. 832×1216 (SDXL). Запомнить размер!
  - Одна ПОЗА для всех слоёв и обоих полов: сгенерить болванку → вытащить ControlNet
    OpenPose-скелет → подавать его во все слои (лицо/волосы/одежда). Так всё
    выравнивается.
  - Лицо/причёску на одном теле менять INPAINT'ом по области головы (тело/поза
    остаются те же). Генерить заново целиком — поза «поплывёт».
  - Пропорции муж./жен. разные → одежду, вероятно, рисовать в двух вариантах.
