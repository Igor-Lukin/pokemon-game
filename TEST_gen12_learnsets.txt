ЭТАЛОН И ПРАВИЛА
----------------
- Источник: PokeAPI /pokemon/{id}.
- Для каждого вида берётся САМАЯ НОВАЯ версия, где у него есть level-up
  данные. Приоритет: scarlet-violet → sword-shield → ultra-sun-ultra-moon →
  omega-ruby-alpha-sapphire → black-2-white-2 → heartgold-soulsilver →
  crystal → gold-silver → yellow → red-blue.
  (BDSP/PLA/XY/SM не используются: старше USUM/ORAS или особый формат PLA.)
- Обновляется ТОЛЬКО learn_method_id=1 (level-up). TM (2), egg (3), tutor (4)
  не тронуты.
- Сопоставление атак — по нормализованному eng_name (lower, только a-z0-9);
  дублей eng_name в каталоге нет (проверено: 0).
- Атаки, отсутствующие в каталоге `attacks`, пропускаются и перечисляются в
  отчёте.
- Если выбранная версия даёт пустой набор — вид не меняется.
