TEST_torch_song — «Песня факела» не повышала Спец. атаку
=========================================================
Дата: 2026-10-27
Часть задачи «Исправления ошибок в разных механиках».

СИМПТОМ
-------
Атака «Песня факела» (Torch Song, attack id=789) наносила урон, но не
повышала Спец. атаку пользователя на +1 (канон: 100%, цель — сам атакующий).

ПРИЧИНА
-------
В движке все изменения статов привязаны к таблице `attack_stat_changes`
(loadStatChanges). Для Torch Song строки не было — атака пришла в gen9-пакете
только с уроном.

ИСПРАВЛЕНИЕ (данные)
--------------------
INSERT INTO attack_stat_changes
  (attack_id, stat_id, stages, target, chance, req_weather)
VALUES (789, 4, 1, 1, 100, 0);

stat_id=4 = Спец. атака (0=HP,1=Atk,2=Def,3=Speed,4=SpAtk,5=SpDef),
target=1 = пользователь, stages=1, chance=100.

ПРОВЕРКИ
--------
[x] PRAGMA integrity_check — ok;
[x] живой бой (тренер NPC 1, временный пользователь): после применения
    Torch Song `player.stat_stages = [0,0,0,0,1,0,0,0]` — индекс 4 (SpAtk)
    стал 1; урон нанесён;
[x] аудит: среди всех УРОН-атак с PokeAPI-эффектом «изменение статов на
    пользователя» других пропущенных строк нет (после фикса — 0);
[x] само-дебаффы (Superpower, Close Combat, Overheat, Draco Meteor, Leaf
    Storm, Psycho Boost, Hammer Arm, Fleur Cannon и статусные Dance/Calm
    Mind/Shell Smash) — строки на месте, не затронуты;
[x] временный пользователь и его покемоны/атаки удалены.
