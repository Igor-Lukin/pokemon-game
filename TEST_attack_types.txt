TEST_attack_types — неверный тип у воздушных атак
==================================================
Дата: 2026-10-27
Часть задачи «Исправления ошибок в разных механиках».

СИМПТОМ
-------
У атак «Рассекающий ветер» (Air Slash), «Воздушное лезвие» (Air Cutter) и
«Насест» (Roost) стоял тип «Боевой» (Fighting, id=7) вместо «Летающий/
Воздух» (Flying, id=10).

ПРИЧИНА
-------
Ошибка данных: в `attacks.type_id` у трёх записей стояло 7.

СДЕЛАНО
-------
UPDATE attacks SET type_id = 10 WHERE id IN (55, 65, 72):
- 55 Рассекающий ветер (Air Slash)
- 65 Воздушное лезвие (Air Cutter)
- 72 Насест (Roost)

ПОЛНЫЙ АУДИТ ТИПОВ
------------------
Прогнал сверку ВСЕХ 791 атак с PokeAPI (/move/{name}) по нормализованному
английскому имени:
- расхождений типа: ровно 3 (все перечисленные выше) — исправлены;
- 4 атаки не нашлись из-за старого написания (Solarbeam, Doubleslap,
  Bubblebeam, Thundershock) — проверены вручную, типы корректны
  (Grass, Normal, Water, Electric);
- прочих несоответствий нет.
