Пунктирная золотая линия — рекомендуемое кольцо. Фиолетовые пунктирные связи — срезки. Клик по локации — уровни, тема спавнов и переходы.

Как проходить

Кольцо можно идти в любую сторону, но уровни сбалансированы под направление «запад → юг → восток → север».

Рекомендуемое кольцо

  1. Голденрод: Площадь, Новый район, Старый район, Вокзал (2–10)
  2. Западный тракт → Стеклянные Скалы → Оливин (5–16)
  3. Затонувший храм → Солончаки → Вархолл (12–22)
  4. Топь Туманов → Кристальный грот → Птичий утёс → Флауренция (17–26)
  5. Цветущий тракт → Заброшенная станция → Лес Забвения → Олстон (21–30)
  6. Северный тракт → Ветряная станция → Пепельная роща → Старая мельница → Голденрод (12–21)

Срезки и возвраты

  • Старый район ↔ Подземный коллектор ↔ Стеклянные Скалы
  • Кристальный грот ↔ Лес Забвения
  • Старая мельница ↔ Вокзал Голденрода
  • Пепельная роща ↔ Северный тракт ↔ Старая мельница

Срезки дают короткие пути, но не отменяют уровни: слабой командой лучше идти по кольцу.
