--------------------------------------------------------------------
ЧТО СДЕЛАНО
--------------------------------------------------------------------
БД:
  - user_pokemons: новая колонка is_starter INTEGER DEFAULT 0
    (миграция идемпотентная, добавлена и в CREATE TABLE для чистой БД).

Backend:
  - POST /api/user/pokemon/{id}/starter — назначает стартового.
    Проверяет владельца и position 1..6, в транзакции снимает флаг у
    остальных, стартовым может быть только один.
  - GetUserTeam отдаёт is_starter.
  - buildPlayerTeam (общая точка дикого и тренерского боя) сортирует
    команду: стартовый первым, далее position. ActiveIdx = первый живой.
  - playerPokemonToBattle отдаёт is_starter в BattlePokemon (PvP-лид).
  - Отправка в питомник снимает is_starter (position=0, is_starter=0).

Frontend:
  - Клик по значку покебола открывает выпадающее меню покемона,
    в нём пункт «Сделать стартовым» (тост и перезагрузка дока
    после выбора). Снятия статуса нет — только назначение.
  - Стартовый выделен: золотая рамка карточки + золотая звезда,
    подсказка на покеболе.
  - В PvP-списке выбора лида стартовый показывается первым и со звездой.

--------------------------------------------------------------------
ЖИВОЙ ПРОГОН (temp DB, сервер :18080)
--------------------------------------------------------------------
1. Регистрация тестового пользователя, 2 покемона (pos 1 и 2).
2. GET /api/user/team -> is_starter=false у обоих.
3. POST /api/user/pokemon/596/starter (pos 2) -> is_starter=true.
4. POST /api/user/pokemon/595/starter (pos 1) -> у 595 true, у 596 false
   (единственность флага подтверждена).
5. POST /api/user/pokemon/596/starter (pos 2) + POST /api/battle/start
   (локация 341) -> в ответе player.id=596, is_starter=true, т.е.
   стартовый выбран первым несмотря на position=2.
6. PRAGMA integrity_check на temp DB: ok.

--------------------------------------------------------------------
ЧТО ПРОВЕРИТЬ ВЛАДЕЛЬЦУ
--------------------------------------------------------------------
- Перезапустить сервер (миграция is_starter применится к боевой БД).
- Ctrl+F5, открыть команду, клик по покеболу -> пункт «Сделать стартовым»:
  звезда/рамка, тост.
- Начать дикий и тренерский бой: первым выходит стартовый.
- PvP: стартовый первым в списке выбора лида.
- Отправить стартового в питомник: статус снимается.
