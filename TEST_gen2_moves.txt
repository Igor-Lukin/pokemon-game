1. КРАТКО
--------------------------------------------------------------------
Повторная проверка показала: 26 атак и лёрнсеты уже были заведены
в другом проходе, но часть механик отсутствовала. Доделано:
  • Rage (+1 Atk при получении урона);
  • Thief (кража held-предмета + персист held_item_id);
  • Triple Kick (10/20/30, отдельная точность на удар);
  • Self Destruct падает в обморок и под Защитой/поглощением;
  • flinch больше не переносится на следующий ход и срабатывает
    только по ещё не ходившей цели;
  • Sacred Fire размораживает пользователя и цель;
  • multi-hit: одна проверка точности, каноническое распределение
    2–5 (3/8, 3/8, 1/8, 1/8);
  • Bind/Wrap: ловушка 2–5 ходов (остальные ловушки не тронуты);
  • схлопнут исторический дубль Fire Blast (id 284 -> id 78).

5.1. ЖИВОЙ PvP ПО HTTP (два аккаунта)
Тестовые аккаунты (созданы в database/pokemon.db, локация 100):
  qa_pvp_a / QaTest123!
  qa_pvp_b / QaTest123!
(только для локальных прогонов; при выкладке в прод удалить/сменить)
Команды (ручной сценарий, requests + cookie-сессии):
  challenge -> incoming -> respond(accept) -> pvp/current -> pvp/lead
  -> pvp/action (оба) -> pvp/state -> pvp/replace -> pvp/forfeit.

Команды:
  A: Mew [Thief, Rage, Triple Kick, Headbutt] + Alakazam
     [Psychic, False Swipe, Seismic Toss, Fury Cutter];
  B: Snorlax (held item id 133) [Mirror Coat, Sacred Fire, Body Slam,
     Steel Wing] + Machamp [Thunder Punch, Stomp, Comet Punch,
     Fury Attack].

Что реально проверено в живом PvP:
  [x] вызов, принятие, lead_select, переход в battling;
  [x] Thief украл held-предмет у Snorlax: у A item=133, у B NULL;
      то же сохранено в user_pokemons после хода;
  [x] Rage: после ответного удара Atk-стадия = 1;
  [x] Triple Kick: в логе hit_count = 3;
  [x] Headbutt: в логе «испуган(а) и пропускает ход»;
  [x] смена A: Mew -> Alakazam, входящий получил удар;
  [x] Mirror Coat: в логе «возвращает удар вдвое»;
  [x] смена B: Snorlax -> Machamp;
  [x] Seismic Toss: в логе damage = 50 (уровень 50);
  [x] Fury Cutter: сила растёт (в логе 7 -> 14, юнит-тест 40/80/160);
  [x] Comet Punch / Fury Attack: multi-hit 2–5 в логе;
  [x] обморок B2 -> фаза await_replace -> replace на Snorlax;
  [x] forfeit B -> finished, winner = A;
  [x] после боя HP и held_item_id сохранены в БД;
  [x] PRAGMA integrity_check = ok.

После прогона тестовые покемоны вылечены (HP=max), B1 снова держит
item 133 — фикстура готова к повторному запуску. Сервер остановлен,
database/pokemon.db-journal удалён.

6. ОГРАНИЧЕНИЯ / НА БУДУЩЕЕ
--------------------------------------------------------------------
• Дикие покемоны и NPC-команды сейчас не носят held-предметы, поэтому
  Thief в wild/trainer чаще всего пишет «крадёт» только при наличии
  предмета; кража реально проверена юнит-тестом и поддержана в PvP.
• Механики TM в игре нет: строки pokemon_attacks method=2 остаются
  данными на будущее.
• Fury Cutter считает серию по SameStreak (общий счётчик подряд
  одинаковых ходов), как и было задумано для Эхо-Волн/Ледяного шара.
• PvP-ветки flinch/Sacred Fire/held-персиста проверены живым HTTP-PvP
  двумя аккаунтами (см. 5.1); GUI-браузер не использовался, но это
  тот же серверный API, что и у клиента.
