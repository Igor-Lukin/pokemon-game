5. КАК ПРОВЕРИТЬ ВЛАДЕЛЬЦУ
====================================================================
1. Бэкапы:
   database/backups/pokemon.db.bak-before-five-roads
   database/backups/pokemon.db.bak-before-single-region
2. Запуск:
   $env:SESSION_KEY = "свой-ключ"
   go run ./server
3. Открыть http://localhost:8080. В БД один регион; новые игроки
   начинают на 300 «Площадь Голденрода».
4. Пройти академический городок:
   Площадь -> Покецентр/Покемаркет -> Академия -> Школьная арена ->
   Тренировочная зона -> Зелёная зона -> Питомник -> Вокзал.
5. Пройти одну из дорог:
   Западную (Оливин), Юго-восточную (Флауренция),
   Юго-западную (Вархолл) или Северо-восточную (Олстон).
6. Проверить безопасную локацию: в Покецентре не должно быть
   диких встреч. Проверить ловлю в Тренировочной зоне.
7. Админка: /admin/regions -> единственный регион 3;
   /admin/locations -> 42 локации; карточка покемона ->
   Habitat Locations -> min/max/rarity.
