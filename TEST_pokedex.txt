====================================================================
TEST_pokedex - доработка покедекса (типы, поиск, эволюции, способности, TM)
Дата: 2026-10-26. Проект: pokemon-game (Go + SQLite + ванильный JS).
====================================================================

1. ЧТО СДЕЛАНО
--------------------------------------------------------------------
1) Клик по плитке типа покемона теперь открывает список всех покемонов
   этого типа (основной ИЛИ вторичный тип). В списке: спрайт, имя, номер,
   иконки типов; клик по карточке открывает детальную карточку.
   Кнопка «◀ Назад» возвращает к сетке типов.
2) Поиск по номеру больше не ограничивается одним совпадением:
   - точный номер;
   - номера, начинающиеся с введённых цифр (25 -> 25, 250..259);
   - имя по подстроке.
   При нескольких совпадениях показывается список (до 200 результатов),
   одно совпадение сразу открывает карточку. Подсказки при вводе — до 20.
3) Вкладка «Эволюции»: под стрелкой пишется способ эволюции:
   «Ур. N», «Дружба», «Обмен», «Предмет: ...», «Камень», а также условия
   (днём/ночью, Атака > Защита и т.п.).
4) Вкладка «Способности»: способность кликабельна, по клику открывается
   существующий попап с описанием из БД.
5) TM/HM-атаки: номер берётся из связанного предмета (TM01, HM02 и т.д.),
   вместо undefined. Если предмета нет — выводится просто «TM».

2. ФАЙЛЫ
--------------------------------------------------------------------
- server/handlers/api/pokedex.go
  * EvolutionLink: method_id/method_name/level/item_id/item_name/condition.
  * AttackInfo: tm_kind (tm/hm), номер TM/HM вычисляется через items.attack_id.
  * AbilityInfo: description из abilities.description.
  * SearchPokemons: поиск по номеру-префиксу + имя, сортировка, LIMIT 200.
  * Новый GetPokemonsByType.
- server/routes/routes.go: GET /api/pokedex/type/{id}.
- client/static/js/pokedex.js: клики по типам, список результатов,
  способы эволюции, кликабельные способности, TM/HM-номера.
- client/static/css/pokedex.css: стили списка результатов, подписи
  способа эволюции, ховер способностей, адаптив.

3. ПРОВЕРКИ
--------------------------------------------------------------------
- go build ./... — ок.
- go vet ./... — ок.
- node --check client/static/js/pokedex.js — ок.
- Живой прогон API (локальный сервер):
  * /api/pokedex/type/13 — 74 покемона (Rock);
  * /api/pokedex/type/2 — 81 покемон (Fire);
  * /api/pokedex/search?q=25 — 25, 250..259;
  * /api/pokedex/search?q=1 — 1, 10..19, 100..199, 1000..1025;
  * /api/pokedex/pokemon/25/full — у Pichu method=friendship,
    у TM-атак есть level и tm_kind=tm, у способностей есть description;
  * /api/pokedex/pokemon/212/full — Scizor: method=trade + item_name;
  * /api/pokedex/pokemon/149/full — Dratini/Dragonair/Dragonite: Ур. 30 / Ур. 55.

4. ЧЕК-ЛИСТ ДЛЯ ВЛАДЕЛЬЦА (браузер, Ctrl+F5)
--------------------------------------------------------------------
[ ] Открыть покедекс, кликнуть по типу (например Огонь) -> список покемонов.
[ ] В списке клик по карточке -> детальная карточка; «Назад» -> снова типы.
[ ] Ввести «25» в поиск: подсказки и Enter показывают несколько номеров.
[ ] Ввести имя (например pikachu): открывается карточка.
[ ] Вкладка «Эволюции»: у стрелок виден способ/уровень/предмет.
[ ] Вкладка «Способности»: клик по способности -> попап с описанием.
[ ] Вкладка «Атаки» -> TM: номера TM01/HM02 без undefined.

5. ПРИМЕЧАНИЕ
--------------------------------------------------------------------
У части старых записей gen1 (например, каменные эволюции Иви) в БД нет
method_id/item_id. Для них способ показывается как «Камень / обмен».
Это данные БД, отдельная задача — заполнить/связать предметы эволюции.
