ЗАДАЧА

После апдейта level-up («Развитие») привести к современному канону остальные
категории лёрнсета gen1–2 (#1–251):

МЕТОДИКА
--------
Источник — PokeAPI /pokemon/{id}. Сопоставление атак по нормализованному
eng_name (lower, только a-z0-9). Неизвестные каталогу атаки пропускаются.

- TM (2): ОБЪЕДИНЕНИЕ machine-совместимости по ВСЕМ поколениям, но только
  для атак, у которых в игре есть TM/HM-предмет (204 предмета: 197 TM + 7 HM).
  Причина: каталог TM-предметов игры смешанный (TM01–TM50 — набор Gen2,
  TM51–TM197 — ходы других поколений). Если брать только новейшую версию,
  легаси-TM (Dynamic Punch, Rollout, Zap Cannon и т.п.) стали бы
  неиспользуемыми. level_learned_at = 0 (номер TM покедекс берёт из предмета).
- Egg (3): самый новый version group, где у вида есть egg-данные
  (SV → SwSh → USUM → ORAS → B2W2 → HGSS → Crystal → GS → RBY).
- Tutor (4): то же правило для tutor-данных.
