====================================================================
TEST_gen1_names - русские имена для gen1 (#10-151)
Исполнитель: opencode. Дата: 2026-10-26.
Источник: pokemon.fandom.com/ru (по выбору владельца).
====================================================================

Задача: 142 покемона gen1 (#10-151) имели английские имена в колонке
`name` (caterpie, pikachu...). Конвенция проекта — русские имена
(у #1-9 и #152-1025 они уже были).

1. Источник и метод
--------------------------------------------------------------------
- Источник: pokemon.fandom.com/ru (MediaWiki API).
  - #10-99: из таблицы «Покедекс Канто» (https://pokemon.fandom.com/ru/wiki/Покедекс_Канто),
    колонка нац. № -> русское имя (90 кириллических имён).
  - #100-151: в той же таблице ссылки английские (страниц нет с английскими
    заголовками); канонические русские заголовки найдены поиском API по
    английскому имени (первый «чистый» результат), затем КАЖДЫЙ заголовок
    проверен по полю `ndex` в infobox соответствующей страницы
    (52/52 совпали, файл verify_ndex.txt; расхождений 0).
- Никаких имён не выдумывал: только заголовки статей fandom.

2. Предмиграционные проверки
--------------------------------------------------------------------
- Конфликтов новых имён с существующими записями pokemons: 0.
- Дубликатов внутри 142 новых имён: 0.
- Незаконченной кириллицы в 10-151 после сборки: 0.
- Бэкап: database/backups/pokemon.db.bak-before-gen1-rune-names.
- PRAGMA integrity_check до миграции: ok.

3. Миграция
--------------------------------------------------------------------
- python+sqlite3, транзакция BEGIN/COMMIT (не нужна остановка сервера —
  сервер не запущен; запись только в pokemons.name).
- 142 UPDATE pokemons SET name=? WHERE id=? (id 10-151).
- Полный лог «старое -> новое»: scratchpad/migration_log.txt
  (копия ниже по ссылке; в репозиторий не копируется по правилу
  db-data-migrations — дампы/скрипты вне репо).

4. Постмиграционные проверки
--------------------------------------------------------------------
- PRAGMA integrity_check: ok.
- pokemons: всего 1025, min/max id = 1/1025 (не тронуто).
- Кириллица в name: 1025/1025 (все покемоны, не только gen1).
- Латиница в name у id 10-151: 0.

5. Известные расхождения источников (принято осознанно)
--------------------------------------------------------------------
- fandom «Покедекс Канто» даёт: Валпикс (#37), Джиглипафф (#39),
  Нидоквин (#31) и т.п. — это перевод/конвенция fandom, НЕ русский
  аниме-дубляж и НЕ ru.wikipedia. Выбрано владельцем проекта.
- ru.wikipedia даёт для #1-9 то же, что уже в БД (Ивизавр #2), но
  fandom-имена #1-9 (Айвизавр) НЕ применялись — имена #1-9 не тронуты
  (задача только про отсутствующие).
- Сверка gen4 (fandom «Поколение IV») с БД: 3 расхождения из 104
  (432 Парагли/Пуругли, 454 Токсикроук/Токсикроак, 493 Аркеус/Арцеус) —
  БД имеет более ранние/свои варианты; НЕ менялись.
- region_johto_map.html содержит английские имена gen1 в спавнах
  (сгенерирован из БД ранее) — при следующей регенерации карты
  имена подтянутся из БД автоматически; вручную файл не правился.
