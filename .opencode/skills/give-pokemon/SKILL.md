# Выдача покемона игроку

Скилл применять **только** по прямой просьбе выдать/выдать заново покемона.
Не использовать для добавления видов, форм, правок движка или экономики.

## 1. Обязательные уточнения

Перед запуском уточни у пользователя (через `question`, можно одним вызовом):

1. **Кому** — username или id игрока (если не назван).
2. **Покемон** — имя или id вида.
3. **Уровень** — 1..100.
4. **Характер** — русское имя или id из таблицы `natures`.
5. **Генокод / IV** — `макс` (=31 везде) или 6 чисел в порядке
   **HP, Atk, Def, Spd, SpA, SpD** (0..31).
6. **Способность** — имя, id или `slot:N`; для вида с одной способностью
   подтверди её. Если способность не важна — `default`.
7. **Размещение** — питомник (по умолчанию) или команда (слот 1..6).

Если что-то уже указано в запросе — не переспрашивай. Пол без просьбы не
уточняй: по умолчанию `random`. Не придумывай характер, IV или способность.

## 2. Свободные EV

Всегда ставь:

```
свободные EV = (уровень - 1) * 3 + 100
```

Пример: уровень 50 → `49*3 + 100 = 247`. Распределённые EV обнуляются.

## 3. Команда

Запускать из корня репозитория (`D:\pokemon-game`):

```powershell
go run ./.opencode/skills/give-pokemon/scripts/give_pokemon.go `
  -user ADMIN `
  -pokemon 681 `
  -level 50 `
  -nature "Непреклонный" `
  -iv max `
  -ability "Королевское построение" `
  -placement nursery
```

Параметры:

| Флаг | Значение |
|---|---|
| `-user` | username или id |
| `-pokemon` | имя вида или id |
| `-level` | 1..100 |
| `-nature` | имя характера или id |
| `-iv` | `max`, одно число или `31,31,31,31,31,31` (HP,Atk,Def,Spd,SpA,SpD) |
| `-ability` | имя, id, `slot:N` или `default` |
| `-placement` | `nursery` (питомник, по умолчанию) или `team` |
| `-gender` | `random` (по умолчанию), `M`, `F`, `N` |
| `-happiness` | 0..255, по умолчанию 0 |

Скрипт сам:

- делает бэкап БД в `database/backups/pokemon.db.bak-before-give-<время>`;
- создаёт экземпляр через `utils.CreateUserPokemon` (пол/привлекательность/
  способность/лёрнсет — по общим правилам);
- обнуляет EV и ставит свободные EV по формуле;
- перезаписывает способность, если она задана вручную;
- печатает id, игрока, вид, уровень, размещение, характер, способность,
  IV, свободные EV, боевые статы и путь бэкапа.

## 4. Проверка и отчёт

- Ошибка скрипта (нет игрока/вида/характера, способность не принадлежит виду,
  команда заполнена) — показать причину и переспросить, не подставлять
  выдуманные данные.
- Если `-placement team`, а все 6 слотов заняты — предложить питомник или
  освободить слот.
- В ответе указать: `user_pokemons.id`, кому, вид, уровень, питомник/слот,
  характер, способность, IV, свободные EV, статы и путь бэкапа.
- Если у игрока открыт клиент — напомнить Ctrl+F5.

## Ограничения

- Не вставлять `user_pokemons` вручную и не дублировать логику создания —
  только `utils.CreateUserPokemon`, затем точечные `UPDATE` из скрипта.
- Не выдавать уровень вне 1..100 и IV вне 0..31.
- Характер/вид/способность должны существовать в БД.
