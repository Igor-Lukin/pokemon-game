ЧТО ТАКОЕ ИГРА СЕЙЧАС
--------------------------------------------------------------------
Веб-игра (Go + SQLite, сервер :8080, клиент — game.html/game.js). Коллекционирование
+ пошаговые бои покемонов. Есть: ловля дикими покеболами, бои с дикими (опыт+эволюция),
NPC-тренеры с умным ИИ-ботом, разведение (яйца), питомник/команда, инвентарь,
карточка тренера, покедекс, held-предметы, TM/HM-предметы, 9 поколений
покемонов (#1–1025), система способностей (каркас + эффекты в бою), камни
эволюции (10 видов, 48 линий), панель онлайн-игроков + PvP-вызов.
Единая точка создания экземпляра — utils.CreateUserPokemon (роллит пол/букву/
способность). Стиль UI — «Каталог/атлас».

E. АРХИТЕКТУРНЫЕ ЗАМЕТКИ ДЛЯ ПРОДОЛЖЕНИЯ
====================================================================
- Единая точка создания экземпляра: utils.CreateUserPokemon (ловля/выдача/вылупление);
  назначение способности — там же. Любое новое создание — ТОЛЬКО через неё.
- Бой серверный, stateful: battleSessions (одиночные) + pvpSessions (PvP), под мьютексами.
  BattleState держит ДВЕ команды: PlayerTeam(+ActiveIdx) и EnemyTeam(+EnemyActiveIdx,
  WildPokemon=указатель на активного врага). PvP переиспользует это (A=Player, B=Enemy).
- Примитивы боя generic по attacker/defender/side (executeDamagingMove и эффект-хелперы)
  — переиспользовать, НЕ плодить второй движок. processTurn (одиночный, ИИ-ход) и
  pvpResolveTurn (два человека) — два оркестратора поверх одних примитивов.
- BattleType: "wild" | "trainer" | "pvp". Ловля гейтится "wild"; ИИ-замены — trainer+
  EnemySmart; awardExp — только "wild". PvP наград/опыта не даёт.
- Способности: abilities.effect_key -> switch в abilities_battle.go; хуки помечены
  «// [ability hook]». Слоты в pokemon_abilities (1/2/3); экземпляр помнит ability_slot
  для ремапа при эволюции.
- Данные покемонов/атак/способностей — СТРОКАМИ в БД (не в коде), правятся python на RDP.
  Движок работает с любым видом. Шкала IV 0..31.
- Эволюции: единая точка выбора ветки — api.checkEvolutionFor. conditions в
  pokemons.evolution_condition (time_day/time_night/atk_gt_def/atk_lt_def/atk_eq_def/
  fairy_move), tie-break — evolution_priority DESC, id ASC. Friendship-строки без
  condition в выборе не участвуют (legacy). См. TEST_evolution_conditions.txt.
- Растр (спрайты) агент качает из сети (болы — league17; gen2–gen5 — Pokémon Showdown .gif).
