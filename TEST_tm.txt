1. КРАТКО
--------------------------------------------------------------------
Добавлены TM/HM-предметы. Использование предмета на покемоне команды
добавляет соответствующую атаку в его список «Доступно к изучению».
Дальше игрок учит её обычным способом: пустой слот / «Заменить атаку».
TM/HM расходуется при успешном использовании. Если TM/HM-атаку выучили
и потом заменили, она удаляется из списка (нужен новый предмет), кроме
случая, когда эта атака уже доступна виду по уровню.

2. РЕШЕНИЯ ВЛАДЕЛЬЦА (из грилинга)
--------------------------------------------------------------------
- Отдельный предмет на каждую атаку.
- Канон Gen2: TM01–TM50 + HM01–HM07.
- Плюс 147 остальных TM-атак из БД (метод tm), нумерация TM51–TM197.
  Итого 204 предмета: 197 TM + 7 HM. (На момент первого сида в БД было
  198 TM-атак; затем параллельно добавили gen3, досозданы ещё 8 TM:
  TM190–TM197. Итог — все не-disabled TM-атаки покрыты.)
- 2 атаки с disabled=1 исключены: Приманка (Substitute),
  Волшебная комната (Magic Room).
- TM и HM одноразовые; тратятся при успешном добавлении атаки в список.
- Несовместимость / уже знает / уже есть в списке / не в команде —
  отказ, предмет НЕ тратится.
- Учить можно только покемонов боевой команды (position 1..6),
  питомник (position 0) не предлагается.
- Совместимость — только pokemon_attacks.learn_method_id = 2 (tm),
  уровень не учитывается.
- В инвентаре одна общая вкладка «TM/HM».
- Иконки: tm.png для TM, hm.png для HM (из Downloads владельца,
  обрезаны/вписаны в 85×85 с прозрачностью).

3. СХЕМА БД (миграции идемпотентны в server/db/database.go)
--------------------------------------------------------------------
- items.attack_id INTEGER — атака, которую открывает TM/HM.
- item_categories.id=10, name='TM/HM'.
- user_pokemon_learnable_attacks.source TEXT DEFAULT 'level'
  ('level' | 'tm' | 'hm').
- user_pokemon_learnable_attacks.source_item_id INTEGER — каким
  предметом открыта атака (для бейджа и удаления при замене).

5. БЭКЕНД
--------------------------------------------------------------------
server/handlers/api/tm.go (новый):
- GET /api/tm/{item_id}/targets — покемоны команды + can_learn/reason.
  Питомник не отдаётся. Уже выученная/уже в списке атака — can_learn=false.
- POST /api/user/pokemon/{id}/use-tm {item_id} — валидирует владельца,
  команду (1..6), наличие предмета, совместимость по method=2,
  что атака не disabled и её ещё нет в списке; в транзакции вставляет
  строку в user_pokemon_learnable_attacks (source='tm'/'hm',
  source_item_id=item_id, level_available=0, is_learned=0) и списывает
  предмет (−1). Повторный вызов с тем же предметом — 409.
- Ответ: {success, message, attack_id, attack_name}.

server/db/items.go:
- Item.AttackID, attack_id в SELECT'ах GetUserInventory / GetItemByID /
  GetAllItems, параметр в CreateItem/UpdateItem.

server/db/learnable.go:
- InitLearnableAttacks при повышении уровня/эволюции переводит TM/HM-строку
  в source='level', если атака стала доступна по уровню.

server/handlers/api/user_pokemon_learnable.go:
- GET learnable отдаёт source, source_item_id, source_item_name.
- LearnAttackHandler: при замене атаки на позиции 1..4, если старая атака
  была source='tm'/'hm' и НЕ доступна по уровню — строка удаляется.
  Если доступна по уровню — остаётся как обычная level-атака.
- Если replace_position не задан: ищется первый свободный слот 1..4,
  иначе 409 «Все 4 слота заняты».

server/routes/routes.go:
- +GET /api/tm/{item_id}/targets
- +POST /api/user/pokemon/{id}/use-tm

9. ОГРАНИЧЕНИЯ / НА БУДУЩЕЕ
--------------------------------------------------------------------
- В pokemon_attacks данные TM/HM неполные у части gen1 (например, Cut/Flash
  есть только у gen2-видов). Это данные, не код: совместимость работает
  ровно по тому, что лежит в pokemon_attacks.
- Магазина/выдачи нет: предметы надо выдавать через /admin/give_item
  или python (user_items). В стартовые наборы не добавлялись.
- Номера TM51–TM197 служебные (сортировка по attacks.id), не канон.
  При добавлении новых поколений/атак с method='tm' доп. номера продолжать
  с TM198 (скрипт-сид можно переиспользовать идемпотентно).
- Доп. TM-атаки, у которых нет ни одного носителя method='tm', не создавались
  (их и так нет в списке).
- Стоимость price=0 — экономика отменена, магазина нет.
- Временный тест-игрок tmtest_1023 и его данные удалены.
