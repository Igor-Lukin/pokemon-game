§0. СВОДКА РЕШЕНИЙ ВЛАДЕЛЬЦА (не отступать)
--------------------------------------------------------------------
- Проект называется POKÉMON Y (тайтлы, логотип шапки, index/login).
- ТЕМЫ РОВНО ДВЕ, обе GTA6-стиля: «Закат» (светлая, ДЕФОЛТ) и
  «Вайс» (тёмная). Переменные — в макете ([data-theme="gta-light"]
  и [data-theme="gta-dark"]). Переключатель в шапке (иконка 🌅/🌃),
  выбор хранить в localStorage, применять до первого рендера
  (inline-скрипт в <head>, чтобы не мигало).
- Шапка: логотип слева; НАВИГАЦИЯ СТРОГО ПО ЦЕНТРУ (Команда/Рюкзак/
  Покедекс/Дневник, position:absolute+translateX(-50%)); справа —
  чип игрока, ✉️ ⚙️ ⏻. Кнопки «Мир» НЕТ. Погоды в шапке НЕТ
  (погода — чип в арте локации, дневник остаётся).
- Центральная зона: 3 колонки 240px / 1fr / 240px —
  «Переходы» | ЦЕНТРАЛЬНЫЙ ФРЕЙМ | «Персонажи».
- Фрейм переключается по навигации: локация (дефолт) / команда /
  рюкзак / карточка покемона. Повторный клик по активной вкладке или
  «←» возвращает локацию. Доки-доки (divDockPanels) для команды и
  инвентаря УБИРАЕМ — они заменяются фреймом. Питомник, тренеркарта,
  дневник, покедекс-панель остаются как есть (доки/панель), их
  открытие фрейм не трогает.
- Локация: арт-блок тянется по высоте (min-height 160px, flex:1),
  НАЗВАНИЕ внутри арта внизу по центру на градиентной подложке;
  ОПИСАНИЕ — оверлей по hover. Под артом: мета-чипы, блок «Здесь
  водятся» (мини-спрайты видов локации + диапазоны уровней из
  pokemon_locations), кнопки «Искать покемона»/«Карта региона».
- БОЙ подменяет ВСЮ центральную зону (все 3 колонки) — как сейчас
  divVisioLoc → divVisioFight, но вся сетка. Чат и «В сети рядом»
  внизу в бою НЕ МЕНЯЮТСЯ.
- Раскладка боя: [колонка игрока 300px | ЖУРНАЛ 1fr | враг 250px].
  Игрок: верх = [смена ВЕРТИКАЛЬНЫМ столбцом 52px | карточка
  (🎒 инвентарь = иконка top-right на карточке; бол из инвентаря =
  ловля, отдельной кнопки «Поймать» НЕТ)]; ниже — «Атаки»
  ВЕРТИКАЛЬНЫМ списком (иконка типа + имя + PP справа).
  Враг: карточка + «Отряд врага» (точки) + «🏳 Сдаться» ВНИЗУ его
  колонки. Кнопки «Смена» НЕТ — смена = клик по иконке команды.
- Журнал боя: формат УЖЕ совпадает с движком (round-header, мини-
  спрайт → атака, крит/эффективность/УРОН) — вёрстка из макета,
  данные те же (рендер addBattleLogEntry сохранить).
- Карточка покемона (в фрейме команды): герой (спрайт, чипы
  пол/привл./стартовый/ур./натура/дружба, EXP-бар, типы), слева
  статы+способность+held-слот, справа атаки+действия (Изучить/
  Покедекс/EV/В питомник). Все данные есть в /api/user/team.
