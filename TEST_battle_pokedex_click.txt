TEST_battle_pokedex_click — покедекс по клику на покемона соперника
====================================================================
Дата: 2026-10-27
Часть задачи «Исправления ошибок в разных механиках».

ЗАДАЧА
------
В бою по клику на карточку покемона соперника открывать его вид в покедексе.

СДЕЛАНО
-------
- client/static/js/game.js, createBattleCard(): для карточки соперника
  (isPlayer === false) добавлен клик — openPokedex() + selectPokemon(pokemon_id)
  (вид, а не id экземпляра). Клики по button/a/input/select игнорируются.
  Функции покедекса вызываются с проверкой typeof — pokedex.js подключён
  после game.js.
- client/static/css/game.css: .battle-card-pokedex { cursor: pointer; }.
- Работает для всех режимов: дикий, тренерский, PvP (карточка соперника
  строится одной функцией).

ПРОВЕРКИ
--------
