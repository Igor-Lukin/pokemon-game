СДЕЛАНО
-------
1) server/db/database.go — seedEvolutionItems():
   - items 151–164, category_id=5 (evolution_stone), effect_type='evolve',
     price=0, image_url=/static/images/items/<stone>.png;
   - 48 связей pokemons.evolution_item_id + evolution_method_id=3;
   - привязка ставится только если evolution_item_id IS NULL (правки админа не
     затираются повторным запуском);
   - для новых связей метод теперь ставится явно (3), а не через COALESCE:
     часть строк (Магнезон/Пробопасс/Лифеон/Глейсеон) лежала с method=1/null,
     и старый COALESCE оставлял их без item-эволюции.

2) server/handlers/api/evolution.go — EvolveWithItem():
   - ключ item-эволюции — evolution_item_id, фильтр по method убран;
   - по-прежнему одна транзакция: списание ровно 1 предмета + UPDATE вида,
     гард по старому pokemon_id; после commit — InitLearnableAttacks и
     RemapAbilityOnEvolve;
   - неподходящий камень — no-op с сообщением, предмет не тратится;
   - повторное применение к уже эволюционировавшему виду — no-op.

3) Новый endpoint GET /api/evolution-items/{item_id}/targets:
   - отдаёт id покемонов команды (position 1..6), для которых этот предмет
     является целью эволюции; нужен UI, чтобы не показывать всех подряд.

4) client/static/js/game.js:
   - при использовании effect_type='evolve' список выбора фильтруется по
     /api/evolution-items/{item_id}/targets;
   - если подходящих нет — сообщение «В команде нет покемонов, которые
     эволюционируют этим предметом»;
   - успех/no-op показываются через showToast; инвентарь и команда обновляются.

5) Иконки 85×85 (как у остальных предметов): fire_stone.png, water_stone.png,
   thunder_stone.png, leaf_stone.png, moon_stone.png, shiny_stone.png,
   dusk_stone.png, dawn_stone.png, ice_stone.png (PokeAPI item sprites,
   апскейл с прозрачностью).

6) server/handlers/api/evolution_item_test.go:
   - тест расширен с 8 до 48 линий (все 10 камней + 4 trade-предмета);
   - проверяются ветвления (Глум→Вилеплум/Беллоссом, Поливирл→Поливрат/
     Политоуд, Иви→5 форм), списание ровно одного предмета, повторный no-op,
     неподходящий предмет и отсутствие предмета.

ПРИМЕЧАНИЯ
----------
- Получение камней: пока только через админку (/admin/items, /admin/give_item);
  автоматическую выдачу/магазин не добавляли (экономика в проекте отключена).
- King's Rock, Metal Coat, Dragon Scale, Up-Grade остаются trade-предметами
  (method=2); механика принимает их по тому же evolution_item_id.
- Не-каменные предметные эволюции gen4–gen9 (яблоки, чайники, броня, свитки,
  Peat Block и т.п.) в эту задачу не входили.
- Каменные строки не участвуют в level-up эволюции (checkEvolutionFor смотрит
  только method 1/4), поэтому предмет обязателен.
