--------------------------------------------------------------------
0. КРАТКО
--------------------------------------------------------------------
В карточке покемона (команда, #team-list) показаны статы Здоровье / Атака /
Защита / Скорость / Спец.атака, а «Спец.защита» ОТСУТСТВУЕТ. Причина — в шаблоне
карточки просто НЕТ блока statContainer для Спец.защиты. Это единственная правка.

БЭКЕНД ТРОГАТЬ НЕ НУЖНО (проверено): API /api/user/team уже отдаёт
special_defense, iv_special_defense, ev_special_defense (user_pokemons.go
GetUserTeam), а обработчик EV (user_pokemon_ev.go DistributeEVHandler) уже
поддерживает stat="special_defense" (и в statMap, и в baseStatIdx). Так что
после добавления блока заработает и отображение, и кнопка распределения EV.

--------------------------------------------------------------------
1. ГДЕ (файл/место)
--------------------------------------------------------------------
Файл: client/static/js/game.js — функция построения карточки команды (loadTeam),
переменная statsHtml. Блоки статов идут подряд: hp -> attack -> defense -> speed
-> special_attack -> (evfree). НУЖНО вставить блок «Спец.защита» СРАЗУ ПОСЛЕ
блока «Спец.атака» (statContainer с data-stat="special_attack") и ПЕРЕД блоком
`<div class="statContainer evfree">`.

Ориентир — конец блока Спец.атаки:
    <div class="statContainer">
        <div class="statTitle">Спец.атака</div>
        ... data-stat="special_attack" ...
    </div>
    <!-- СЮДА вставить новый блок Спец.защиты -->
    <div class="statContainer evfree">   <!-- этот блок уже есть, его НЕ трогаем -->

2. ЧТО ВСТАВИТЬ (точный блок — 1:1 паттерн соседних статов)
--------------------------------------------------------------------
                        <div class="statContainer">
                            <div class="statTitle">Спец.защита</div>
                            <div class="statVal${nc('special_defense')}">${p.special_defense}</div>
                            <div class="statTren"></div>
                            <div class="button btnEvSub rednumber justicon" style="visibility: hidden;"><span class="icon icomoon icon-minus">+</span></div>
                            <div class="progressbar barEV"><div style="width: ${((p.ev_special_defense || 0) / 126) * 100}%;" title="${p.ev_special_defense || 0}/126"></div></div>
                            <div class="button btnEvAdd greennumber justicon" style="visibility: ${evPlusAttr};" data-stat="special_defense" data-pokid="${p.id}"><span class="icon icomoon icon-plus">+</span></div>
                        </div>

Пояснения (всё уже есть в области видимости этой же функции):
  - nc('special_defense') — подсветка по характеру (nc сравнивает имя стата с
    p.increased_stat/decreased_stat; строка 'special_defense' валидна);
  - p.special_defense / p.ev_special_defense — приходят из /api/user/team;
  - evPlusAttr — видимость «+», как у остальных статов;
  - data-stat="special_defense" — обработчик EV его уже понимает (btnEvAdd
    привязывается по .btnEvAdd, см. bindTeamEvents/аналог в game.js).
