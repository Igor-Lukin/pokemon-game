Что сделано
--------------------------------------------------------------------
P0-1. Пароль убран из лога входа.
  server/handlers/auth/login.go — log.Println("Login attempt:", username).

P0-2. Ошибки БД при регистрации не утекают клиенту.
  server/handlers/auth/register.go — детали пишутся в log; клиенту
  "Registration failed" (500). Нарушение UNIQUE (username/email) -> 409
  "Пользователь с таким именем уже существует".

P0-3. Валидация регистрации до INSERT.
  username: trim, 3..20, только [a-zA-Z0-9_];
  email: trim, <=100, содержит '@' и '.';
  password: 8..72 символа (72 = лимит bcrypt по байтам).
  Ошибки — 400 с русским текстом; «Пароли не совпадают» тоже по-русски.

P0-4. SameSite у сессионной cookie.
  server/session/store.go — SameSite: http.SameSiteLaxMode + комментарий
  про Secure (включать после перехода на https).

P1-1. Rate-limit на /login и /register.
  server/routes/ratelimit.go (новый) — in-memory map[IP] + mutex,
  скользящее окно, фоновая очистка.
  server/routes/routes.go — /login POST: 10 за 10 минут;
  /register POST: 5 за час. Превышение -> 429.

P1-2. Телепорт закрыт.
  server/handlers/api/user.go — /api/user/move проверяет, что целевая
  локация есть в location_exits текущей локации игрока; иначе
  400 "Сюда нет пути".

P1-3. Лечение только в Покецентре.
  server/handlers/api/heal.go — читает locations.has_healing по
  users.location_id; если 0 -> 400 "Здесь нет Покецентра".

P1-4. Запрет кэша для API.
  server/routes/routes.go — noCacheAPIMiddleware: для путей /api и /api/*
  выставляет Cache-Control: no-store. /static и /images не затронуты.

P1-5. Таймауты HTTP-сервера.
  server/main.go — http.Server с ReadHeaderTimeout=10s, ReadTimeout=30s,
  WriteTimeout=60s, IdleTimeout=120s.

P2-1. Чат безопасен до будущего включения.
  client/static/js/game.js — appendMessage строит DOM через
  createElement/textContent (без innerHTML); ws URL берётся из
  location.host с wss при https. Сам чат по-прежнему не включён
  (серверного ws-обработчика нет) — как и требовало ТЗ.

P2-2. Разведение: лимит яиц и транзакция.
  server/handlers/api/breeding.go — не более 3 яиц на игрока
  (400 "Инкубатор полон (3 яйца)"); проверка лимита + дубликата пары +
  INSERT выполняются на одном соединении в BEGIN IMMEDIATE, затем COMMIT
  (ROLLBACK при любой ошибке) — двойной сабмит не создаёт 2 яйца.

P2-3. UX-мелочи.
  U1. client/static/js/login.js — после 200 от /login сразу
      window.location="/game"; промежуточная кнопка и дублирующий POST
      /game убраны.
  U2. client/static/js/game.js — все alert() заменены на showToast()
      (поиск дикого, ловля/предметы, эволюция, TM/HM, питомник и т.п.).
  U3. server/handlers/api/location.go — в ответ локации добавлен has_wild
      (EXISTS по pokemon_locations). client/static/js/game.js и game.css:
      на локации без диких иконка 🌿 получает класс .header-icon.is-disabled
      (серая, cursor not-allowed, title «Здесь нет диких покемонов»),
      клик игнорируется.

Живой прогон (за владельцем; чек-лист)
--------------------------------------------------------------------
Перезапустить сервер (старый процесс на :8080), затем:
1. Регистрация: валидная -> вход; дубликат username/email -> 409 и
   понятный текст; короткий/мусорный username, плохой email, короткий
   пароль -> 400.
2. Логин: в логе сервера нет пароля; cookie pokemon-session имеет
   SameSite=Lax.
3. Rate-limit: 11-й POST /login подряд с одного IP -> 429; после окна
   снова пускает; /register — 6-я регистрация за час -> 429.
4. Карта: клик по легальному переходу работает; прямой POST
   /api/user/move на далёкую локацию -> 400 "Сюда нет пути".
5. Покецентр: POST /api/heal с дороги -> 400; в 301/310/315/320/325
   лечит HP/PP как раньше.
6. Заголовки: любой /api/* -> Cache-Control: no-store; /static/* —
   без no-store.
7. Разведение: 4-е яйцо -> 400; двойной сабмит пары -> одно яйцо.
8. UI: логин в один клик; вместо alert — тосты; 🌿 на площади серая с
   подсказкой, на маршруте с дикими работает.
