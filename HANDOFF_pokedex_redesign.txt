1. ЧТО ЗА ПРОЕКТ (минимум контекста)
--------------------------------------------------------------------
Браузерная игра про покемонов. Go-бэкенд + SQLite + серверные HTML-шаблоны +
статика (css/js). Тебе интересен ТОЛЬКО фронт покедекса. Боевую часть и
HANDOFF_moves.txt не трогаем — это соседняя кампания.

Покедекс — выезжающая панель со справочником всех 151 покемона: поиск,
сетка типов, детальная карточка (картинка, статы, типы, вкладки Эволюции /
Атаки / Способности / Ареалы / Прочее).

2. ФАЙЛЫ ПОКЕДЕКСА (где что лежит)
--------------------------------------------------------------------
- client/static/css/pokedex.css      — ВЕСЬ стиль покедекса (~420 строк).
                                        ГЛАВНЫЙ файл этой задачи.
- client/static/js/pokedex.js        — логика: открытие/закрытие панели, поиск,
                                        сборка HTML детальной карточки через
                                        innerHTML, вкладки, навигация ◀/▶.
- server/templates/game.html         — разметка панели (строки ~146-172): каркас
                                        #pokedex-panel > .pokedex-content >
                                        (.pokedex-search, .pokedex-subtitle,
                                        .pokedex-types-section, #pokedex-detail,
                                        .pokedex-collapse-btn). Подключение css —
                                        строка 11, подключение js — строка 349.
- client/static/css/game.css         — стиль ОСТАЛЬНОЙ игры. НЕ править (только
                                        читать как референс палитры, см. §3).
- server/handlers/api/pokedex.go     — API (JSON). Трогать только по §5.

Данные приходят с бэка (менять не надо), формат ответа /api/pokedex/pokemon/{id}/full:
  id, name, description, height, weight (kg/m, могут быть null),
  primary_type / secondary_type (имена), primary_type_id / secondary_type_id,
  image_url (gif покемона), category_power (0..10 — рисуется звёздами),
  experience_group, base_stats{hp,attack,defense,speed,special_attack,
  special_defense}, evolution_chain[{id,name,image_url}], attacks[{name,
  learn_method(level-up/egg/tm/tutor), level, category_id(1физ/2спец/3статус),
  type_id, type_name, power, accuracy, pp, ...}], abilities[{name,is_hidden}],
  locations[{name,rarity}].
Иконки типов: /static/images/types/{type_id}.png (1..18).

3. ПРОБЛЕМА (почему переделываем) — со слов владельца: «не нравится, как выглядит»
--------------------------------------------------------------------
Диагноз тимлида (конкретика, чтобы было от чего отталкиваться):

(A) СТИЛИСТИЧЕСКИЙ РАЗНОБОЙ С ИГРОЙ. Вся игра — тёплая, светлая, «мягкая»:
    фон body = linear-gradient(180deg,#f9f2d6,#ffdbcc), текст #3a2c2a, шрифт
    Inter, скруглённые углы, лёгкие тени, акцент-зелёный #44cc99. А покедекс —
    инородное тёмное «стекло»: фон rgba(30,30,40,0.85)+blur, жёлтый акцент
    #ffd966. Смотрится как кусок из другого приложения.

(B) CSS ПОЛУ-РАЗОБРАН. Много ПУСТЫХ правил — визуально элементы «голые»:
    - .pokedex-collapse-btn:hover {}          — пусто
    - .pokedex-collapse-btn                    — без фона (кнопка невидимая)
    - .suggestion-item:hover {}                — пусто (нет отклика на наведение)
    - .attack-block:hover                      — почти незаметный
    - .tab-btn, .attack-subtab-btn             — без фона/формы, только текст
    - .attack-block                            — без фона, только цветная полоска слева
    Итог: кнопки/вкладки/подсказки выглядят недоделанными.

(C) КАРТОЧКА ТЕСНАЯ И ПЛОСКАЯ. Статы — простой серый grid 3-в-ряд без визуала
    (нет полосок-баров), звёзды силы текстом, вкладки без выделения активной
    кроме тонкой жёлтой черты, эволюции/атаки — минималистично и невыразительно.

(D) МЕЛОЧИ. Панель фиксированной ширины 35% сверху-справа, скролл всего блока;
    на узких экранах (@media 800px) — 80%. Проверить, что не разъезжается.

4. ЧТО НЕЛЬЗЯ ЛОМАТЬ (JS завязан на эти имена — иначе покедекс перестанет работать)
--------------------------------------------------------------------
pokedex.js ищет элементы по id и генерит карточку с фикс. классами. Если
МЕНЯЕШЬ имя класса/id в разметке — ОБЯЗАТЕЛЬНО поправь и pokedex.js (можно, ты
делаешь фронт), но лучше СОХРАНИТЬ имена и менять только оформление.

id (используются в JS напрямую — трогать опасно):
  #pokedex-panel (класс .open открывает панель), #pokedex-icon (📘 в шапке),
  #pokedex-collapse-btn, #pokedex-search-input, #pokedex-types-grid,
  #pokedex-detail, #pokedex-suggestions (создаётся из JS), #attack-subcontent,
  #tab-evolution/#tab-attacks/#tab-abilities/#tab-locations/#tab-other,
  #pokedex-prev-btn/#pokedex-next-btn.

Классы, по которым JS вешает поведение / генерит карточку:
  .pokedex-search, .search-icon, .pokedex-subtitle, .pokedex-types-section,
  .type-icon(+img), .pokedex-suggestions/.suggestion-item,
  .pokedex-card, .pokedex-nav/.pokedex-nav-title/.pokedex-nav-btn,
  .card-top/.card-left/.card-right, .pokemon-gif(-wrapper), .weight-height,
  .category-power, .pokemon-types-icons/.type-icon-img,
  .pokemon-name-id/.pokemon-name/.pokemon-id, .pokemon-exp-group,
  .pokemon-stats/.stat-row/.stat-label, .pokemon-description,
  .tabs/.tab-btn(.active)/.tab-content(.active),
  .attack-subtabs/.attack-subtab-btn(.active)/.attack-subcontent,
  .attack-grid.two-columns/.attack-block(+.attack-physical/-special/-status)/
  .attack-type/.attack-name/.attack-level/.attack-type-icon/.no-attacks,
  .evolution-chain/.evolution-item/.evolution-img/.evolution-arrow,
  .ability-list/.hidden-ability, .pokedex-table.

Механики, которые должны продолжать работать после рестайла:
  - клик по 📘 открывает панель (класс .open), стрелка ▲ сворачивает;
  - .open делает transform в видимое положение (сейчас translateY) — сам эффект
    выезда можно переделать, но открытие/закрытие обязано работать;
  - ввод в поиск -> выпадающие подсказки -> клик по подсказке -> карточка;
  - активная вкладка = класс .active на .tab-btn и на .tab-content;
  - подвкладки атак так же через .active;
  - категория атаки красится по .attack-physical/-special/-status (сохранить
    смысл: физ/спец/статус различимы цветом).

  8) Способности/Ареалы: список и таблицу привести в порядок (зебра/разделители).
  9) Кнопки навигации ◀/▶ и «свернуть ▲» — сделать видимыми и приятными

Свобода: конкретные оттенки, тени, радиусы, анимации — на твой вкус в рамках
